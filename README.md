# Band Generator App

A beginner Python console program that suggests a band name. It asks for the city you were born in and the name of your pet, then joins the two into a band name. Written as an early exercise in reading user input and combining strings.

## Features

- Interactive prompts in the terminal
- Combines the two answers into a band name, for example `Pune Bruno`

## Tech stack

- Python 3 (standard library only, no dependencies)

## Getting started

Prerequisites: Python 3 installed.

```bash
git clone https://github.com/anshumantewary-pm/Band-Generator-App.git
cd Band-Generator-App
python "Band Name Generator.py"
```

Example session:

```text
Welcome to the band generator app
In which city were you born:Pune
What is the name of your pet:Bruno
Your band name is:Pune Bruno
```
